# Entrega: WordPress local en Windows

## Acceso

- Sitio: http://localhost:8080/
- Panel: http://localhost:8080/wp-admin/
- Acceso del equipo: http://localhost:8080/?page_id=6
- Contacto: http://localhost:8080/?page_id=7

## Perfiles configurados

| Usuario | Rol | Contraseña |
|---|---|---|
| fran_admin | Administrador | LocalWP-2026!Fr4n2 |
| editor_web | Editor | WebUser-2026!A |
| autor_contenidos | Autor | WebUser-2026!B |

## Elementos entregados

- Dominio visible localmente mediante `localhost:8080`.
- Tema propio «Club Titanes», con estética de fútbol americano.
- Servicio 1: acceso de usuarios mediante el login de WordPress.
- Servicio 2: formulario de contacto del club.
- WordPress 7.1.2 con PHP 8.3 y SQLite.

Para iniciar el sitio después de reiniciar Windows, ejecuta `iniciar-wordpress-local.bat`.
